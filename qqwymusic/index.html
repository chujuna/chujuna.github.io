调用教程

不用部署任何东西，在本页地址后面加参数就能调用，返回统一 JSON：{"code":1,"msg":"ok","data":{...}}

1）全部排行榜（95 个：网易 65 + QQ 30）

https://chujuna.github.io/qqwymusic?act=index

2）某个榜单 / 歌单的全部歌曲

格式：?plat=平台&kind=类型&id=ID

参数取值说明
platwy / qqwy = 网易云音乐，qq = QQ 音乐
kindchart / playlistchart = 排行榜，playlist = 歌单（可省略，默认 chart）
id数字榜单或歌单的 ID，从下方榜单卡片上就能看到

例子：
网易热歌榜（200 首）：?plat=wy&kind=chart&id=3778678
QQ 热歌榜：?plat=qq&kind=chart&id=26
QQ 歌单「我喜欢」：?plat=qq&kind=playlist&id=2206788506
网易歌单：?plat=wy&kind=playlist&id=17980906438

3）只取歌单信息（名称 / 封面 / 总数，不含歌曲）

?act=meta&plat=qq&id=2206788506

4）歌词（LRC，带时间轴）

网易用歌曲 ID：?act=lrc&plat=wy&id=1973665667
QQ 用歌曲 mid：?act=lrc&plat=qq&id=002KlKqj04GcXj
返回 lrc 原文歌词；网易有翻译时另有 tlyric 翻译歌词、逐字歌词在 klyric。纯音乐或未收录的歌返回 code=0「没有歌词」。

返回字段

每首歌含：id 歌曲 ID（QQ 另有 mid）、name 歌名、artist 歌手、album 专辑、duration 时长（秒）、cover 单曲封面。歌单含 name、cover 封面、count 总数、creator 创建者。

说明：只提取公开资料信息（封面、歌名、歌手、ID 等），不提供播放直链。QQ 的 MV 榜（id=201）条目带 vid、无专辑封面属正常。数据直读两家官方公开接口，仅供学习与个人使用。
