一、反馈提示

点完之后，页面怎么告诉你「成功了 / 出错了 / 请确认」

提醒气泡Tooltip

也叫：悬停提示、气泡提示

鼠标悬停（手机上长按/点击）时，旁边冒出一小段说明文字，移开就消失。不打扰阅读，专门解释图标和缩写。

↑ 悬停或点住按钮试试

「给这个按钮加一个提醒气泡（Tooltip），鼠标悬停时显示‘点击查看帮助’。」

轻提示Toast

也叫：吐司提示、消息通知条

操作完成后，屏幕底部或顶部飘出一句短消息（如「保存成功」），几秒后自动消失，不需要点任何按钮。

点完看屏幕最底部

「保存成功后，用轻提示（Toast）在底部弹出‘已保存’，2 秒后自动消失。」

模态弹窗Modal

也叫：对话框、弹出层

页面中央弹出一个框，背景变暗，必须先处理它（确认或取消）才能继续操作。适合删除确认、重要通知。

「点击删除时弹出模态弹窗（Modal）二次确认，有‘取消’和‘确认删除’两个按钮。」

抽屉Drawer

也叫：侧边滑出面板

从屏幕边缘（通常是右侧）滑出一个面板，放详情、筛选条件或菜单，点空白处或关闭按钮收回去。

「点击订单后，从右侧滑出抽屉（Drawer）显示订单详情，不要跳转新页面。」

气泡确认框Popconfirm

也叫：小气泡确认

比弹窗更轻：点删除后，就在按钮旁边冒出一个小气泡问「确定吗？」，不用遮住整个页面。适合不那么严重的确认。

确定要删除吗？删了不能恢复。
点上方按钮试试

「删除按钮用气泡确认框（Popconfirm），在按钮上方弹出小确认，不要用大弹窗。」

警告提示条Alert / Banner

也叫：横幅通知、提示横条

页面顶部或内容区上方的一条彩色横条，长期显示重要信息：黄色是提醒，红色是错误，绿色是成功。

⚠️ 注意：你的套餐将于 3 天后到期，请及时续费。
✕ 提交失败：手机号格式不正确，请检查后重试。

「在页面顶部加一条黄色警告提示条（Alert），写‘套餐即将到期’，带关闭按钮。」

角标 / 徽标Badge

也叫：未读红点、数字角标

图标右上角的小红点或数字，表示「有 3 条未读消息」；也可以是文字小标签，如「新品」「热卖」。

新品上架

「给消息图标加数字角标（Badge），显示未读数量，超过 99 显示 99+。」

加载动画Loading / Spinner

也叫：转圈、等待指示器

数据还没加载完时显示的转圈或跳动动画，告诉用户「正在处理，别急」，避免以为页面卡死了。

点按钮后，这里会先转圈再出结果

「数据加载时显示加载动画（Spinner），加载完成后再显示内容，不要白屏。」

气泡卡片Popover

也叫：浮层卡片、信息浮窗

比提醒气泡大、比弹窗小：点一下元素，旁边浮出一张小卡片，能放头像、简介和按钮。看用户资料、商品速览常用。

🍊 橙子君
资深买手 · 已发布 128 篇测评
点按钮，资料卡浮出来

「鼠标悬停头像时弹出气泡卡片（Popover），显示头像、简介和关注按钮。」

通知面板Notification Panel

也叫：消息面板、通知中心下拉

点铃铛后展开的一列消息清单，不用跳页面就能看完最近通知。配合角标数字一起用。

📦 你的包裹已送达10 分钟前
💬 小林回复了你的评论1 小时前
🎁 会员日优惠券已到账昨天

「点右上角铃铛展开通知面板，列出最近消息和时间，不跳转页面。」

结果状态页Result

也叫：成功/失败提示页

提交完表单、付完款后，整页换成一个大图标 + 结果说明 + 下一步按钮。比轻提示更正式，适合支付、下单这种大事。

✅
支付成功
订单号 202611190031，可在「我的订单」查看

「支付完成后显示结果页（Result）：大号成功图标、订单号和‘查看订单/返回首页’两个按钮。」

带撤销的操作条Snackbar

也叫：撤销提示条

轻提示的加强版：提示里带一个「撤销」按钮，删错了、移错了能立刻反悔。邮箱删信、文件移入回收站常用。

删完会出现带「撤销」的提示条

「删除后底部出现带‘撤销’按钮的操作条（Snackbar），5 秒内可点撤销恢复。」

全屏加载遮罩Fullscreen Loading

也叫：整页等待、全局 Loading

整个页面被半透明层盖住，中间转圈，期间什么都点不了。适合提交订单、切换页面这种必须等完的场景。

点完整个页面会被盖住 1.5 秒

「提交时显示全屏加载遮罩，半透明黑底加转圈和‘提交中…’，期间禁止重复点击。」

二、导航

帮用户知道「我在哪、能去哪」的所有入口

顶部导航栏Navbar

也叫：顶栏、Header

页面最上方固定的一条，通常放 Logo、主要栏目链接和登录/头像。用户在任何页面都能快速跳到其他栏目。

🍊 橙子商城首页商品我的

「页面顶部做一个导航栏（Navbar），左边放 Logo，右边放首页、商品、我的三个链接。」

面包屑Breadcrumb

也叫：路径导航

一行「首页 › 商品 › 手机 › iPhone」的小字，显示你现在在网站的哪一层，点任意一层能跳回去。

首页›数码产品›手机›iPhone 17

「在标题上方加面包屑导航（Breadcrumb）：首页 › 分类 › 当前页，每一级可点击。」

标签页 / 选项卡Tabs

也叫：页签切换

同一块区域里放几组内容，点顶部标签来回切换，不用跳页面。常用于「商品详情 / 参数 / 评论」。

这里是商品详情：面料、产地、使用说明都写在这里。

「详情区用标签页（Tabs）切换：详情、参数、评论三个页签，点击切换内容不刷新页面。」

下拉菜单Dropdown

也叫：下拉列表

点一下按钮，下方展开一列选项；点完选项或点别处就收起。适合放「更多操作」、头像菜单、筛选选项。

点按钮展开菜单，再点一个选项

「头像旁边加下拉菜单（Dropdown），点开有：个人设置、我的订单、退出登录。」

分页器Pagination

也叫：页码、翻页

内容太多时分成一页一页，底部有 1 2 3 … 页码按钮。和「无限滚动」是两种相反的加载方式，二选一。

正在看：第 1 页的内容

「列表每页显示 10 条，底部加分页器（Pagination），显示页码和上一页/下一页。」

步骤条Stepper

也叫：流程进度、向导

把一件事拆成几步横着排开，显示「走到第几步了」。常用于下单、注册、填写多页表单。

吸顶 / 粘性定位Sticky

也叫：滚动固定

元素滚到顶部时「粘」住不动，继续往下滚它也一直可见。导航栏、分类标题、购买按钮常用。

分段控制器Segmented Control

也叫：切换按钮组

几个选项并排在一个圆角框里，选中一个高亮。比标签页更轻，常用于「日 / 周 / 月」「列表 / 网格」切换。

当前查看：日数据

「数据切换用分段控制器（Segmented Control）：日、周、月、年四个选项并排，选中高亮。」

侧边栏Sidebar

也叫：左侧导航、侧边菜单

固定在页面左侧的一列菜单，后台、管理页、文档站最常见。空间不够时能折叠成只剩图标的一条。

主内容区
点左侧菜单切换栏目；点下方按钮，侧边栏会折叠成图标条。

「左侧做固定侧边栏（Sidebar）放主菜单，可折叠成只显示图标，右侧是内容区。」

底部导航栏Bottom Navigation

也叫：底部标签栏、Tab Bar

手机 App 和移动网页最底下的一排图标：首页、发现、消息、我的，拇指最容易够到，一般 3–5 个。

点一点，选中的会高亮

「移动端底部加固定导航栏：首页、发现、消息、我的，图标加文字，选中高亮。」

汉堡菜单Hamburger Menu

也叫：三横线菜单、移动端菜单按钮

那个「☰」三横线按钮，手机上导航装不下时，把菜单藏进它里面，点开才展开。

🏠 首页 🛍 全部商品 📦 我的订单 ⚙️ 设置
点 ☰ 展开 / 收起菜单

「手机端顶栏只留 Logo 和汉堡菜单按钮（☰），点开向下展开全部导航链接。」

锚点导航 / 滚动高亮Scrollspy

也叫：页内目录、滚动监听

长页面旁边一列小目录：点一下平滑滚到对应段落；自己滚动时，当前段落的目录项自动高亮。

产品介绍往下滚动这个小框，顶部目录会跟着变色。点目录也能直接跳过去。

「长页面右侧加锚点目录，点击平滑滚动到对应章节，滚动时自动高亮当前章节（Scrollspy）。」

返回顶部Back to Top

也叫：一键置顶、回顶部按钮

页面滚下去一段后，右下角才冒出一个 ↑ 按钮，点一下平滑滚回最上面。长文章、长列表必备。

宫格导航Grid Menu

也叫：金刚区、图标快捷入口

一排排「图标 + 两个字」的方格入口，手机首页最常见：充值、缴费、外卖、打车……功能多的时候用它一屏摆完。

「首页功能入口用宫格导航（金刚区）：每行 4 个，图标在上、名称在下。」

三、内容展示

内容怎么排、怎么收起、怎么翻看

折叠面板Accordion

也叫：手风琴、折叠列表

一列标题，点标题展开下面的内容，再点收起。常见问题（FAQ）页几乎都用它，省地方又整齐。

在「我的订单」里点申请退款，1–3 个工作日原路退回。
付款后 48 小时内发货，偏远地区顺延 1 天。
发货前可以，在订单详情页点「修改地址」即可。

「常见问题用折叠面板（Accordion）：点问题展开答案，一次只展开一个。」

轮播图Carousel

也叫：幻灯片、Banner 轮播

几张图自动一张张滑过去，下方有小圆点表示第几张，也能手动左右滑。首页顶部的大图区就是它。

活动一 · 满减
活动二 · 新品
活动三 · 会员日
自动轮播中，点圆点可切换

「首页顶部加轮播图（Carousel），3 张图每 3 秒自动切换，带圆点指示，可手动滑动。」

卡片Card

也叫：信息卡、商品卡

把一条信息装在一个带边框/阴影的方块里：图在上、标题、简介、价格、按钮。列表页的基本单位就是一张张卡片。

¥399

「商品用卡片（Card）展示：上方图片、下方名称和简介，底部左边价格、右边购买按钮。」

时间线Timeline

也叫：时间轴

一条竖线串起按时间发生的事件，新在上、旧在下。物流轨迹、更新日志、个人动态都用它。

骨架屏Skeleton

也叫：加载占位图

内容加载前，先显示和最终页面长得差不多的灰色块轮廓（带闪光），加载完再换成真内容。比转圈更不晃眼。

「列表加载时用骨架屏（Skeleton）占位，灰块闪烁，数据到了再替换成真实内容。」

空状态Empty State

也叫：无数据提示

列表里什么都没有时，不是留一片空白，而是显示一个图标 + 一句「暂无订单」+ 一个引导按钮。

📭
还没有订单
去逛逛商城，看看有什么喜欢的

「列表为空时显示空状态（Empty State）：一个插图、一句‘暂无数据’和一个引导按钮。」

跑马灯 / 滚动公告Marquee

也叫：走马灯、滚动字幕

一行文字从右往左不停滚动，常见于商城公告、直播间提示。适合放一条不需要点开看的通知。

「顶部加一条跑马灯公告（Marquee），文字从右向左循环滚动，鼠标悬停时暂停。」

图片灯箱Lightbox

也叫：查看大图、图片预览

点一张小图，全屏变暗、图片放大居中显示，再点任意处关闭。相册和商品图必备。

点任意一张图放大看

「点击图片打开灯箱（Lightbox）全屏看大图，带左右切换和关闭按钮。」

树形结构Tree

也叫：目录树、层级列表

像文件夹一样层层展开的列表：点父级展开子级。适合文件目录、组织架构、多级分类。

      • 📄 年度报告.docx
      • 📄 预算表.xlsx
      • 🖼 旅行.jpg

「文件列表做成树形结构（Tree），点击文件夹展开/收起子级，层级用缩进区分。」

数据表格Table

也叫：数据表、列表表格

行列整齐地摆数据：订单、成绩、库存都靠它。表头常可点击排序，行多时配分页器一起用。

基础列表List

也叫：信息列表、条目列表

最朴素的排版：一行一条，左边名称、右边数值或箭头。设置页、账单页、消息页的基本形态。
