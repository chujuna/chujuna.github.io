JSON 调用教程

在本页地址后加参数，直接返回 JSON（code 1 成功 / 0 失败）：

点歌

返回：song 歌名、singer 歌手、cover 封面、music 直链（QQ 音乐 M4A 320kbps，带时效 vkey）、quality 音质。

去水印

text 传整段分享文案，或只传短链；url 参数只传短链也行。返回：title 标题、desc 文案、cover 封面、author 作者、avatar 头像、video_url 无水印视频地址（抖音 CDN）、source_url 原分享链接。

原样返回
